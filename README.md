# Project Guide

## معرفی پروژه

این پروژه یک وب‌سایت چندمنظوره است که شامل بخش‌های مختلف مانند فروشگاه آنلاین، خدمات دیجیتال، آموزش و سیستم فریلنسری خواهد بود.

هدف پروژه ساخت یک پلتفرم قابل توسعه با ساختار منظم و کدنویسی استاندارد است.

# قوانین کار تیمی

* قبل از تغییرات بزرگ، با اعضای تیم هماهنگ کنید.
* هر قابلیت جدید در یک Branch جدا توسعه داده شود.
* قبل از Merge کردن، کد بررسی شود.
* کدها باید خوانا و قابل فهم باشند.
* از قرار دادن اطلاعات حساس مثل رمز دیتابیس داخل GitHub خودداری کنید.

---

# نحوه کار با Git

دریافت آخرین تغییرات:

```bash
git pull
```

ساخت Branch جدید:

```bash
git checkout -b feature-name
```

ثبت تغییرات:

```bash
git add .
git commit -m "description of changes"
```

ارسال تغییرات:

```bash
git push
```

# راه‌اندازی پروژه

1. پروژه را Clone کنید.

```bash
git clone project-url
```

2. فایل تنظیمات دیتابیس را وارد کنید.

3. دیتابیس MySQL را ایجاد کنید.

4. پروژه را روی سرور محلی اجرا کنید.

---

# نکات توسعه

* قبل از اضافه کردن قابلیت جدید، ساختار فعلی پروژه را بررسی کنید.
* کدهای تکراری ایجاد نکنید.
* امنیت را در اولویت قرار دهید.
* تغییرات مهم را در Commit توضیح دهید.
